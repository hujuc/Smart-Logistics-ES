# Project 8 – Shipping & Logistics Management System

The Smart Logistics Management System (SLMS) is a comprehensive platform designed to optimize the entire logistics lifecycle, from order creation to final delivery. Built as a modular monolith, it integrates key actors in the supply chain: managers, warehouse staff, drivers, and customers, into a unified ecosystem.

Key features include:

- **Centralized Management:** Real-time dashboards for logistics managers to monitor KPIs and optimize carrier selection.
- **Warehouse Automation:** Streamlined workflows for shipping label generation and pickup coordination.
- **Driver Empowerment:** A dedicated PWA for drivers to manage routes, manifests, and capture proof of delivery.
- **Customer Transparency:** Self-service portal for real-time order tracking and exception reporting.
- **AI Assistance:** Integrated chatbot powered by Google Gemini for contextual support across all roles.

The system leverages a robust tech stack including Java Spring Boot, Next.js, PostgreSQL, Kafka, and Keycloak, ensuring scalability, security, and high performance.
