## 1. DHL API

- **What it does**:
  - Shipment creation and label generation.
  - Rate calculation and delivery time estimation.
  - Tracking shipments.
  - Scheduling pick-ups.
  - Customs document management.

- **Link**: [DHL API](https://developer.dhl.com/api-reference/dhl-express-mydhl-api?language_content_entity=en)

---

## 2. FedEx API

- **What it does**:

## 4. Multi-Carrier Alternatives

### Shippo

- **What it does**:
  - Integrates multiple carriers (including DHL, FedEx, and UPS) into a single API.
  - Compares rates across carriers.
  - Creates labels and tracks shipments.

- **Link**: [Shippo API](https://goshippo.com)

### AfterShip

- **What it does**:
  - Focuses on shipment tracking.
  - Supports over 1,100 carriers.

- **Link**: [AfterShip API](https://www.aftership.com)
