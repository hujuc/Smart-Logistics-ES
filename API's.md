## 1. DHL API

- **O que faz**:
  - Criação de envios e etiquetas.
  - Cálculo de tarifas e prazos de entrega.
  - Rastreio de encomendas.
  - Agendamento de recolhas.
  - Gestão de documentos para as aduanas.

- **Link**: [DHL API](https://developer.dhl.com/api-reference/dhl-express-mydhl-api?language_content_entity=en)

## 4. Alternativas Multi-Transportadora

### Shippo

- **O que faz**:
  - Integra várias transportadoras (incluindo DHL, FedEx e UPS) numa única API.
  - Compara tarifas entre transportadoras.
  - Criação de etiquetas e rastreamento de encomendas.

- **Link**: [Shippo API](https://goshippo.com)

### AfterShip

- **O que faz**:
  - Focado no rastreamento de encomendas.
  - Suporta mais de 1.100 transportadoras.

- **Link**: [AfterShip API](https://www.aftership.com)
