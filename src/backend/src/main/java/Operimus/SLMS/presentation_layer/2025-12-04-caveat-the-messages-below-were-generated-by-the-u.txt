     1.3 ToolDefinition.java - Tool metadata for Gemini
     package Operimus.SLMS.business_layer.chatbot_module.dto;

     public record ToolDefinition(
         String name,
         String description,
         List<ToolParameter> parameters
     ) {
         // Convert to Gemini's function declaration format
         public Map<String, Object> toGeminiFormat() {
             Map<String, Object> properties = new HashMap<>();
             List<String> required = new ArrayList<>();
             
             for (ToolParameter param : parameters) {
                 Map<String, Object> paramDef = new HashMap<>();
                 paramDef.put("type", param.type());
                 paramDef.put("description", param.description());
                 if (param.enumValues() != null) {
                     paramDef.put("enum", param.enumValues());
                 }
                 properties.put(param.name(), paramDef);
                 
                 if (param.required()) {
                     required.add(param.name());
                 }
             }
             
             return Map.of(
                 "name", name,
                 "description", description,
                 "parameters", Map.of(
                     "type", "object",
                     "properties", properties,
                     "required", required
                 )
             );
         }
     }

     4.1 ToolExecutor.java
     package Operimus.SLMS.business_layer.chatbot_module.tools;

     @Service
     @Slf4j
     @RequiredArgsConstructor
     public class ToolExecutor {
         
         private final ToolRegistry toolRegistry;
         private final ObjectMapper objectMapper;
         
         private static final int MAX_EXECUTION_TIME_MS = 5000;
         
         /**
          * Execute a tool call with authorization and validation
          */
         public ToolResult execute(ToolCall toolCall, UserContext context) {
             log.info("Executing tool: {} for user: {} (role: {})", 
                 toolCall.name(), context.userId(), context.role());
             
             try {
                 // 1. Get tool
                 Tool tool = toolRegistry.getTool(toolCall.name());
                 
                 // 2. Check authorization
                 if (!isAuthorized(tool, context)) {
                     log.warn("Unauthorized tool access: {} by role: {}", 
                         toolCall.name(), context.role());
                     return ToolResult.error(
                         toolCall.id(),
                         "You don't have permission to use this tool"
                     );
                 }
                 
                 // 3. Validate parameters
                 validateParameters(tool, toolCall.arguments());
                 
                 // 4. Execute with timeout
                 ToolResult result = executeWithTimeout(tool, toolCall, context);
                 
                 log.debug("Tool execution completed: {} - success: {}", 
                     toolCall.name(), result.success());
                 
                 return result;
                 
             } catch (ToolNotFoundException e) {
                 log.error("Tool not found: {}", toolCall.name());
                 return ToolResult.error(toolCall.id(), e.getMessage());
                 
             } catch (UnauthorizedToolAccessException e) {
                 log.error("Unauthorized access: {}", e.getMessage());
                 return ToolResult.error(toolCall.id(), e.getMessage());
                 
             } catch (Exception e) {
                 log.error("Tool execution failed: {}", toolCall.name(), e);
                 return ToolResult.error(
                     toolCall.id(),
                     "Tool execution failed: " + e.getMessage()
                 );
             }
         }
         
         private boolean isAuthorized(Tool tool, UserContext context) {
             Set<String> allowedRoles = tool.getAllowedRoles();
             return allowedRoles.contains("*") || 
                    allowedRoles.contains(context.role()) ||
                    context.allRoles().stream().anyMatch(allowedRoles::contains);
         }
         
         private void validateParameters(Tool tool, Map<String, Object> arguments) {
             List<ToolParameter> params = tool.getParameters();
             
             for (ToolParameter param : params) {
                 if (param.required() && !arguments.containsKey(param.name())) {
                     throw new IllegalArgumentException(
                         "Missing required parameter: " + param.name()
                     );
                 }
                 
                 // Type validation
                 if (arguments.containsKey(param.name())) {
                     Object value = arguments.get(param.name());
                     validateParameterType(param, value);
                 }
             }
         }
         
         private void validateParameterType(ToolParameter param, Object value) {
             switch (param.type()) {
                 case "string" -> {
                     if (!(value instanceof String)) {
                         throw new IllegalArgumentException(
                             "Parameter %s must be a string".formatted(param.name())
                         );
                     }
                 }
                 case "integer" -> {
                     if (!(value instanceof Number)) {
                         throw new IllegalArgumentException(
                             "Parameter %s must be a number".formatted(param.name())
                         );
                     }
                 }
                 case "boolean" -> {
                     if (!(value instanceof Boolean)) {
                         throw new IllegalArgumentException(
                             "Parameter %s must be a boolean".formatted(param.name())
                         );
                     }
                 }
             }
         }
         
         private ToolResult executeWithTimeout(Tool tool, ToolCall toolCall, UserContext context) {
             ExecutorService executor = Executors.newSingleThreadExecutor();
             Future<ToolResult> future = executor.submit(() -> 
                 tool.execute(toolCall.arguments(), context)
             );
             
             try {
                 return future.get(MAX_EXECUTION_TIME_MS, TimeUnit.MILLISECONDS);
             } catch (TimeoutException e) {
                 future.cancel(true);
                 return ToolResult.error(
                     toolCall.id(),
                     "Tool execution timed out after " + MAX_EXECUTION_TIME_MS + "ms"
                 );
             } catch (Exception e) {
                 return ToolResult.error(toolCall.id(), "Execution error: " + e.getMessage());
             } finally {
                 executor.shutdown();
             }
         }
     }

         /**
          * Generate response with optional userId for tool authorization
          */
         public ChatResponse generateResponse(
             ChatRequest request, 
             String frontend, 
             String role,
             String userId
         ) {
             // Check for commands
             if (request.message().trim().startsWith("/")) {
                 return handleCommand(request.message().trim());
             }
             
             try {
                 // 1. RAG pipeline (unchanged)
                 log.debug("Generating embedding for message: {}", request.message());
                 float[] queryEmbedding = embeddingService.generateEmbedding(request.message());
                 
                 log.debug("Querying Pinecone for relevant documents");
                 List<PineconeQueryResponse.Match> relevantDocs = ragService.queryRelevantDocuments(
                     queryEmbedding, frontend, role, request.locale(), DEFAULT_TOP_K
                 );
                 
                 String augmentedPrompt = ragService.augmentPrompt(request.message(), relevantDocs);
                 List<Map<String, String>> messages = buildConversationMessages(
                     request.conversationHistory(), augmentedPrompt
                 );
                 
                 // 2. Get available tools for user role
                 List<ToolDefinition> tools = toolRegistry.getToolDefinitionsForRole(role);
                 log.debug("Available tools for role {}: {}", role, 
                     tools.stream().map(ToolDefinition::name).toList());
                 
                 // 3. Tool calling loop
                 String systemPrompt = buildSystemPrompt(frontend, role);
                 UserContext userContext = new UserContext(userId, role, Set.of(role));
                 
                 GeminiChatResponse response = geminiClient.generateCompletionWithTools(
                     systemPrompt, messages, tools
                 );
                 
                 int iterations = 0;
                 while (response.hasFunctionCalls() && iterations < MAX_TOOL_ITERATIONS) {
                     log.info("LLM requested {} tool calls", response.getFunctionCalls().size());
                     
                     // Execute each tool call
                     List<ToolResult> toolResults = new ArrayList<>();
                     for (GeminiFunctionCall functionCall : response.getFunctionCalls()) {
                         ToolCall toolCall = new ToolCall(
                             UUID.randomUUID().toString(),
                             functionCall.name(),
                             functionCall.args()
                         );
                         
                         ToolResult result = toolExecutor.execute(toolCall, userContext);
                         toolResults.add(result);
                         
                         log.debug("Tool {} executed: success={}", 
                             functionCall.name(), result.success());
                     }
                     
                     // Add tool results to conversation and continue
                     messages = addToolResultsToMessages(messages, toolResults);
                     response = geminiClient.generateCompletionWithTools(
                         systemPrompt, messages, tools
                     );
                     
                     iterations++;
                 }
                 
                 // 4. Extract final text response
                 String finalResponse = response.getText();
                 List<String> sourceDocIds = ragService.extractChunkIds(relevantDocs);
                 
                 return new ChatResponse(finalResponse, sourceDocIds);
                 
             } catch (Exception ex) {
                 log.warn("Error in tool-enabled response, falling back: {}", ex.getMessage());
                 return generateFallbackResponse(request, frontend, role);
             }
         }
         
         private List<Map<String, String>> addToolResultsToMessages(
             List<Map<String, String>> messages,
             List<ToolResult> toolResults
         ) {
             List<Map<String, String>> updatedMessages = new ArrayList<>(messages);
             
             // Add tool results as system messages
             for (ToolResult result : toolResults) {
                 String resultMessage = result.success() ?
                     "Tool result: " + result.result() :
                     "Tool error: " + result.errorMessage();
                 
                 updatedMessages.add(Map.of("role", "system", "content", resultMessage));
             }
             
             return updatedMessages;
         }

     }

  🎯 Security Flow Example

  Scenario: Anonymous user on landing page asks "What's the status of order 123?"

  1. LandingPageChatBffController passes role="ANONYMOUS", userId=null
  2. ChatbotService calls toolRegistry.getToolDefinitionsForRole("ANONYMOUS")
  3. ToolRegistry filters tools → returns empty list (no tools allow ANONYMOUS)
  4. Gemini LLM called without any tools
  5. Response: Generic answer from RAG docs only (e.g., "I don't have access to specific order data. Please log in to track your order.")

  Scenario: Customer asks "What's the status of order 123?" (doesn't own it)

  1. CustomerChatBffController passes role="CUSTOMER", userId="customer-uuid-456"
  2. LLM decides to use order_status tool with orderId=123
  3. ToolExecutor.isAuthorized() checks: CUSTOMER ∈ allowedRoles? ✅ Yes
  4. OrderStatusTool.execute() fetches order 123 (owned by customer-uuid-789)
  5. Authorization check: customer-uuid-456 != customer-uuid-789 → DENIED
  6. Returns: ToolResult.error("You can only view your own orders")
  7. LLM receives error, responds: "I'm sorry, I can only show you information about your own orders."

  ⚠️ Minor Security Note

  There's a subtle information disclosure (timing attack): A customer trying different order IDs could potentially infer if an order exists:
  - Order 123 (exists, not theirs): "You can only view your own orders"
  - Order 999 (doesn't exist): "Order not found"

  Mitigation options (if needed):
  1. Return generic "Order not found" for both cases
  2. Add rate limiting to prevent enumeration attacks
  3. Log suspicious access patterns for monitoring

  Verdict: This is a low-risk issue for most applications, but fixable if needed.
